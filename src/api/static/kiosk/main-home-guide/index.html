한국어
사용 방법
모약 키오스크에서 간편하게 약품을 구매해 보세요.
1
구매 방법을 선택해 주세요
의약외품 즉시 구매 또는 본인인증 필요 약품 구매를 선택합니다.
2
원하는 약품을 찾아주세요
검색하거나 카테고리를 선택해 원하는 약품을 확인합니다.
3
약품을 장바구니에 담아주세요
구매할 약품과 수량을 확인한 후 장바구니에 담습니다.
4
결제 방법을 선택해 주세요
장바구니에서 구매할 약품을 확인하고 원하는 결제 방법을 선택합니다.
5
약품을 수령해 주세요
결제가 완료되면 화면의 안내에 따라 자판기에서 약품을 수령합니다.
