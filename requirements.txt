# 배포 전에 반드시 넣어야 하는 환경변수 (Render > Environment)
#
# 패키지만 깔고 키를 안 넣으면 서버는 뜨지만 기능이 조용히 죽는다.
# 어떤 키가 없으면 무엇이 안 되는지 적어 둔다. 값의 예시·설명은 .env.example 참고.
#
#   필수 ─ 없으면 핵심 기능이 안 됨
#     OPENAI_API_KEY            챗봇 답변·임베딩·상담 요약·음성 전사  (없으면 /chat 500)
#     PINECONE_API_KEY          약 정보 검색                        (없으면 /chat 500)
#     DATABASE_URL              상담·처방·결제 기록 (팀 Supabase)
#                               안 넣으면 로컬 SQLite 로 떨어지는데, Render 무료는
#                               디스크가 휘발성이라 재배포마다 기록이 날아간다
#
#   기능별 ─ 없으면 그 기능만 꺼짐 (서버는 정상)
#     ANTHROPIC_API_KEY         알약 사진 인식 (1위 93.3%)
#                               없으면 예전 OpenCV+Google 방식(64.7%)으로 자동 대체
#     GOOGLE_VISION_API_KEY     위 예전 방식의 각인 읽기. 둘 다 없으면 정확도 9.2%
#     SUPABASE_URL              회원가입·로그인
#     SUPABASE_ANON_KEY         〃
#     SUPABASE_SERVICE_ROLE_KEY 〃  ※ 서버 전용 비밀값 — 앱·웹페이지에 절대 넣지 말 것
#     DAILY_API_KEY             화상 상담방 생성
#     KAKAO_JS_KEY              지도 화면
#     MAP_DATABASE_URL          지도·DUR·알약 조회용 Supabase (읽기 전용)
#     CONSULT_AUTH_SECRET       로그인 토큰 서명 (32자 이상)
#     EYAK_SERVICE_KEY          e약은요 수집 스크립트 전용 (서버 구동에는 불필요)
#
# 긴 키를 대시보드에 붙여넣을 때 줄바꿈이 끼면 HTTP 헤더 오류가 난다
# (Render 에서 로그인이 503 으로 죽은 적 있음). config.py 가 공백을 떼지만,
# 붙여넣을 때 한 줄인지 눈으로 확인할 것.
# ──────────────────────────────────────────────────────────────────────────
